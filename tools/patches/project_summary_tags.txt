================================================================================
           โครงสร้าง TAG สำหรับแม่แบบเอกสารสรุปโครงการ (DOCX TEMPLATE TAGS)
================================================================================

[คำอธิบายรูปแบบ]
- Tag ในเอกสาร Word (.docx) จะใช้รูปแบบ {tag_name} หรือ {#tag_name}...{/tag_name} สำหรับ Loop
- แท็กที่มีเครื่องหมาย [Shared] คือแท็กที่ระบบจะดึงค่าอัตโนมัติจากแบบเสนอโครงการเดิม
- แท็กที่มีเครื่องหมาย [New] คือแท็กใหม่เฉพาะของแบบสรุปโครงการ

--------------------------------------------------------------------------------
แผ่นที่ 1 : บันทึกข้อความนำส่งรายงานสรุปโครงการ
--------------------------------------------------------------------------------
1. ส่วนราชการ: {department_name} หรือ {memo_dept} [Shared]
   - ชนิด: TEXT
   - คำอธิบาย: ชื่อหน่วยงาน/แผนกวิชา เช่น แผนกวิชาเทคโนโลยีสารสนเทศ

2. วันที่: {doc_date} หรือ {doc_date_full} [Shared/Auto]
   - ชนิด: DATE (พ.ศ. ไทย)
   - คำอธิบาย: วันที่ทำบันทึกข้อความ เช่น ๒๘ สิงหาคม ๒๕๖๙

3. เรื่อง: {subject} [Shared/Auto]
   - ชนิด: TEXT
   - คำอธิบาย: เรื่องที่นำส่ง เช่น รายงานผลการดำเนินงานโครงการ...

4. เนื้อหาย่อหน้า 1: {memo_paragraph1} [New]
   - ชนิด: LONGTEXT
   - คำอธิบาย: ข้อความเกริ่นนำตามที่ได้รับอนุมัติให้ดำเนินโครงการ

5. เนื้อหาย่อหน้า 2: {memo_paragraph2} [New]
   - ชนิด: LONGTEXT
   - คำอธิบาย: ข้อความสรุปผลการดำเนินงาน บัดนี้ได้ดำเนินการเสร็จสิ้นแล้ว

6. ชื่อผู้รายงาน: {leader_name} หรือ {reporter_name} [Shared]
   - ชนิด: TEXT
   - คำอธิบาย: ชื่อ-นามสกุล ผู้เสนอ/ผู้รับผิดชอบโครงการ

7. ตำแหน่งผู้รายงาน: {leader_position} หรือ {reporter_position} [Shared]
   - ชนิด: TEXT
   - คำอธิบาย: ตำแหน่งของผู้รายงาน เช่น ครู คศ.๑

--------------------------------------------------------------------------------
แผ่นที่ 2 : ปกรายงานสรุปผลการดำเนินงานโครงการ
--------------------------------------------------------------------------------
1. ชื่อโครงการ: {title} หรือ {project_name} [Shared]
   - ชนิด: TEXT
   - คำอธิบาย: ชื่อโครงการเต็ม

2. ปีงบประมาณ: {fiscal_year} [Shared]
   - ชนิด: TEXT/NUMBER
   - คำอธิบาย: เช่น ๒๕๖๙

3. รูปภาพปก: {%cover_image} หรือ {cover_image} [New]
   - ชนิด: IMAGE
   - คำอธิบาย: รูปภาพกิจกรรมหลักสำหรับใส่หน้าปก

4. ชื่อผู้จัดทำ/ผู้รับผิดชอบ: {leader_name} [Shared]
   - ชนิด: TEXT

5. ตำแหน่งผู้จัดทำ: {leader_position} [Shared]
   - ชนิด: TEXT

6. ฝ่ายงาน: {division_name} [Shared]
   - ชนิด: TEXT
   - คำอธิบาย: เช่น ฝ่ายวิชาการ, ฝ่ายบริหารทรัพยากร, ฝ่ายพัฒนากิจการฯ, ฝ่ายแผนงานฯ

แผ่นที่ 3 : แบบรายงานผลการดำเนินงานโครงการ
--------------------------------------------------------------------------------

--- ส่วนที่ 1 ข้อมูลเบื้องต้น ---

   - ชนิด: DATE

3. เรื่อง: {report_subject} [Shared/Auto]
   - ชนิด: TEXT
   - ตัวอย่าง: รายงานผลการดำเนินงานการปฏิบัติการ/{title}

4. ย่อหน้า 1 (บทนำ): {intro_paragraph} [New]
   - ชนิด: LONGTEXT

5. 1. ชื่อโครงการ: {title} หรือ {project_name} [Shared]
   - ชนิด: TEXT

6. 2. งาน/แผนก ที่รับผิดชอบ: {department_name} [Shared]
   - ชนิด: SELECT/DROPDOWN (งาน / แผนก / อื่นๆ)

7. 3. ฝ่ายที่รับผิดชอบ: {division_name} [Shared]
   - ชนิด: SELECT/DROPDOWN (4 ฝ่าย)

8. 4. สอดคล้องกับการประกันคุณภาพการศึกษา: {qa_alignment} [Shared]
   - ชนิด: CASCADE SELECT (3 มาตรฐาน > ประเด็น > ด้าน)
   - แท็กย่อย (ถ้าแยกคอลัมน์):
     - มาตรฐาน: {qa_standard}
     - ประเด็น: {qa_issue}
     - ด้าน: {qa_aspect}

--- ส่วนที่ 2 ข้อมูลงาน / ผลการดำเนินงาน ---
1. วัตถุประสงค์งาน: {#objectives}{item}{/objectives} [Shared]
   - ชนิด: TABLE_LOOP / LIST

2. เป้าหมาย:
   - เชิงปริมาณ: {target_quantitative} [Shared]
   - เชิงคุณภาพ: {target_qualitative} [Shared]

3. การดำเนินงาน: {operation_status} [New]
   - ชนิด: SELECT (ดำเนินงานแล้ว / กำลังดำเนินการ / ยังไม่ได้ทำ)

4. ระยะเวลาตามแผน:
   - วันเริ่มต้น: {start_date} [Shared]
   - วันสิ้นสุด: {end_date} [Shared]

5. ระยะเวลาปฏิบัติจริง:
   - วันเริ่มต้นจริง: {real_date_start} [New]
   - วันสิ้นสุดจริง: {real_date_end} [New]

6. รายงานผลการปฏิบัติงานตามกิจกรรม:
   - 6.1 ผลการปฏิบัติงานเชิงปริมาณ: {actual_result_quantitative} [New] (LONGTEXT)
   - 6.2 ผลการปฏิบัติงานเชิงคุณภาพ: {actual_result_qualitative} [New] (LONGTEXT)

7. สรุปงบประมาณและการใช้จ่ายเงิน:
   - งบประมาณที่ระบุในแผนงาน: {total_budget} [Shared] (NUMBER)
   - งบสนับสนุนจากหน่วยงานอื่น:
     - ชื่อหน่วยงาน: {other_organization} [New] (TEXT)
     - จำนวนเงินสนับสนุน: {other_budget} [New] (NUMBER)
   - สรุปงบประมาณที่ได้รับจัดสรร: {allocated_budget} [New] (NUMBER)
   - สรุปผลงานการใช้จ่ายเงิน (ยอดใช้จริง): {expenditure_performance} [New] (NUMBER/TEXT)
   
   - 7.1 ประเภทของเงินที่ใช้: {budget_fund_type} [New]
     - ชนิด: SELECT
     - ตัวเลือก:
       1) เงินงบประมาณ
       2) เงินรายได้สถานศึกษา
       3) เงินอุดหนุนโครงการสนับสนุนค่าใช้จ่ายในการจัดการศึกษาตั้งแต่ระดับอนุบาลจนจบการศึกษาขั้นพื้นฐาน
       4) เงินอุดหนุนทั่วไป (งานวิจัย)
       5) เงินงบรายจ่ายอื่น
       
   - 7.2 ปริมาณการใช้เงิน: {spending_status} [New]
     - ชนิด: SELECT
     - ตัวเลือก:
       1) ใช้เงินตามแผน
       2) ใช้เงินต่ำกว่าแผน ({spending_diff_amount} บาท)
       3) ใช้เงินสูงกว่าแผน ({spending_diff_amount} บาท)
